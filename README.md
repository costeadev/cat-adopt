Centro de adopción de gatitos
==============================

Aplicación de escritorio en Java que simula un centro de adopción de gatos.

## Requisitos
- Código en inglés
- Documentación, comentarios y UI en español
- Control de version en Git (en un repo de GitHub)

---

## 📖 Descripción

El usuario puede explorar una colección de gatos, ver sus imágenes y adoptar aquellos que le gusten.

Al adoptar un gato, se le asigna un nombre personalizado y se guarda en una base de datos local. El gato deja de aparecer en la lista de gatos disponibles.

El usuario puede posteriormente consultar sus gatos adoptados y modificar sus nombres.

---

## 🖥️ Pantallas de la aplicación

La aplicación contará con tres vistas principales:

- Pantalla de bienvenida
- Navegador de gatos disponibles
- Panel de gatos adoptados

---

## 🎯 Funcionalidades

- Explorar gatos disponibles
- Adoptar gatos y asignarles un nombre
- Visualizar gatos adoptados
- Renombrar gatos adoptados

---

## 🌐 Fuente de datos

Las imágenes de los gatos se obtendrán a través de [TheCatAPI](https://thecatapi.com/).

---

## ⚙️ Detalles técnicos

- **UI**: JavaFX + FXML  
- **Backend**: Java  
- **Base de datos**: SQLite  
- **Consumo de API**: HttpClient
